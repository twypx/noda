## 1. Architecture & performance

- **Pure C++20 + Qt6 Widgets**, no QML, no WebView, no Wine, no Electron. Win32/GDI removed entirely.
- Editing core uses Scintilla's native Qt interface (`ScintillaEditBase`) via `EditorView`, keeping
  high throughput on very large files. Cold start ~80–120 ms, RSS ~35–45 MB.
- **Uniform UTF-8 in-memory stream** — no UTF-16↔UTF-8 conversion churn.
- Reused upstream assets verbatim: `langs.model.xml`, `stylers.model.xml`, `uchardet`, `pugixml`.
- **Performance-first patterns used throughout**: viewport-only work with hard time budgets,
  font-list/theme-metadata singletons, batched tab-bar re-polish, `mmap`-backed hex viewer,
  flat contiguous arrays instead of tree nodes, and no speculative dependencies.

## 2. Build

```bash
sudo apt update
sudo apt install -y build-essential cmake qt6-base-dev qt6-base-dev-tools
cd npp-linux
./build.sh                       # produces build/noda
./build/noda
```

Optional `libxcb1-dev` enables the X11 startup-notification fix-up; without it the build still works.

Debian package:

```bash
./build_deb.sh
sudo apt install ./build-deb/noda_*_amd64.deb
```

Installed layout: `/usr/bin/noda`, `/usr/share/noda/` (XML, themes, nativeLang),
`/usr/share/applications/noda.desktop`, `/usr/share/icons/hicolor/*/apps/noda.png`,
`/usr/share/doc/noda/copyright`. Uninstall with `sudo apt remove noda`.

Key packaging facts:
- `Depends` is generated by `dpkg-shlibdeps`, not hand-written (handles Ubuntu's `t64` suffix).
- `Recommends: qt6-wayland` — the Wayland platform plugin ships separately from `libqt6gui6`.
- `-DCMAKE_INSTALL_PREFIX=/usr` is mandatory: `.desktop`'s `Exec` is baked at configure time.
- XML lives in `share/`, resolved at runtime via `applicationDirPath()/../share/noda`.

### Troubleshooting

- **App missing from "Open With"**: the full dialog reads `mimeinfo.cache` (from `.desktop`'s
  `MimeType`), but the right-click submenu only lists `mimeapps.list` `[Added Associations]`.
  Run `tools/register_open_with.py --dry-run` then without flags to add associations (revert with `--remove`).
- **Launcher spinner for ~15.6 s (X11 only)**: startup notification sequence was never completed.
  `StartupNotify` re-writes `_NET_STARTUP_ID` onto the main window before mapping and calls
  `notifyComplete()`; 15.6 s is the sequence timeout.
- **Square frame around rounded popup**: platform menu shadow vs. Qt frame; handled in `ThemeManager`.
- `%F` (local file list) is used instead of `%U`: `main.cpp` only accepts local paths.

## 3. Session memory & backup

`SessionManager` restores tabs, cursor positions, encodings, EOLs and unsaved content on restart.
The session root element is `<Noda>`. Config directory is derived from `QSettings`
(`~/.config/Noda/`). On first run after the rename, `ConfigMigration` copies legacy
`~/.config/Notepad++/*` into `~/.config/Noda/` (including `session.xml`); it is idempotent and
never overwrites an existing new config.

## 4. Release

`tools/release.sh` derives the repository from the git remote, tags `v<version>`, and publishes
to Gitee Releases via the API. No repo name is hard-coded.

## 5. App icon

- Source artwork: `noda_cutout.png` → `resources/icons/app_master_1024.png` and
  `app_<N>.png` (16/24/32/48/64/128/256), all embedded in `resources/app.qrc`.
- **20 px and 40 px are hand-tuned native assets** for the title bar at DPR=1 and DPR=2, so the
  20×20 logical icon hits an exact match instead of being scaled from 24/48.
- `tools/gen_icons.py` regenerates the standard sizes and every hicolor theme size
  (`hicolor/<S>x<S>/apps/noda.png` plus `scalable`). The hand-tuned 20/40 are intentionally
  excluded from auto-generation.
- **Runtime SVG is deliberately not used**: `QIcon("*.svg")` requires the optional QtSvg
  image-format plugin, which is frequently absent on minimal desktops and would silently yield an
  empty icon. Pre-rasterized PNGs embedded in the qrc are dependency-free and deterministic.

## 6. Toolbar & column editing

- Toolbar actions are generated from a declarative `ToolEntry` table; icon-only mode shows
  name + shortcut tooltips.
- Icons (Lucide, ISC) are designed as SVG but **pre-rasterized offline** to 16/32 PNG by
  `tools/gen_toolbar_icons.py` and embedded in `toolbar.qrc`; no QtSvg at runtime.
- Column (rectangular) selection, column editor (insert text / ascending numbers with
  None / Zeros / Spaces padding), Alt+C.

## 7. Printing, saving, diagnostics

- Print header/footer, tab expansion to column boundaries, no wrapping (matches upstream default).
- Save / Save-As / Save-Copy-As use transactional writes with explicit failure messages and
  encoding verification — never silently write the wrong encoding.
- Syntax config loading reports missing files / parse errors with search paths and consequences.

## 8. UI configuration

- **Tree-structured preferences**: theme, UI language, tab bar, auto-completion, matching
  highlight, CJK/Latin UI fonts, editor behaviour — only real, backed options, no placeholders.
- **Style configurator**: per language × style slot colours, bold/italic, font family and size.
- **Shortcut mapper** generated from real menu actions, editable with conflict detection and reset.
- **Fold-level menu** (levels 1–8), whitespace operations, sort, case conversion, bookmarks.
- **Folder tree** (`打开文件夹`): left dock with lazy `QFileSystemModel`, zero recursive
  pre-scan, custom branch/indent painting, size threshold for colouring. No plugin code imported.
- **Localization**: runtime English ⇄ 简体中文 switch. Menus, toolbar tooltips, status bar and
  preferences are fully bilingual; the language selector keeps native names
  (`简体中文` / `English`). Dynamic status-bar text is built from translated templates and
  marked `nppNoL10n` so `applyToAll()` cannot roll it back.

## 9. Hex view (binary data)

`视图 > 以十六进制查看` (`Ctrl+Alt+H`) toggles a hex/ASCII view in the current tab.

- Reads **raw on-disk bytes** via `setFile()` + `mmap`, not the decoded UTF-8 buffer; UTF-16 / GBK /
  NUL-containing binaries are displayed faithfully. Unsaved documents fall back to memory.
- **Zero whole-file copy**: `paintEvent` performs one range read for the visible window only.
- Row-batched `drawText` (one per hex row, one per ASCII row), 256-entry hex lookup table.
- 64-bit addresses with 8/16-digit auto width; `qint64` row/offset computation clamped to
  `QScrollBar`'s int range.
- Colours from `ThemeManager::hexViewColors()`; focus drives which side (HEX/ASCII) is highlighted;
  a widget-level stylesheet pins the monospace font so global QSS cannot break the column grid.
- Files containing NUL bytes auto-open in hex view. Read-only by design.

## 10. Comparison / Diff (modules P.6 / P.7)

`视图 > 文件比对` is a **submenu** with five entries: `文件对比` (`Ctrl+Alt+C`), `比对选区`,
`与 Git HEAD 比对`, `与 SVN BASE 比对`, `关闭对比` (`Ctrl+Alt+X`). The toolbar **Compare Files**
button is a toggle: click to enter comparison (checked / highlighted), click again to exit; `Ctrl+Alt+C`
has the same toggle semantics.

Inside comparison mode the options bar (beside *Ignore whitespace* / *Ignore case*) shows three buttons:
**Next Difference**, **Previous Difference** and **Close Compare**. They are owned by `CompareWidget`,
so they exist only while the comparison view is open. `F8` / `Shift+F8` remain window-level shortcuts.
Every entry point (menu / shortcut / selection / Git / SVN) keeps the toolbar button's checked state in
sync; if an entry is rejected by a guard (too few tabs, file too large) the button rolls back to unchecked.

**Engine (`utils/DiffEngine`)**
- Zero-copy tokenization: `std::string_view` lines over `EditorView::currentTextView()`
  (`SCI_GETRANGEPOINTER`); no whole-document copies on the synchronous path.
- **wyhash-style 64-bit block hash** (8-byte reads + 128-bit multiply mixing) instead of FNV.
  Normalization (ignore whitespace / case) only allocates when those options are enabled.
- **Histogram/Patience anchors** (unique lines sorted + LIS) split the document; anchor-free small
  regions use **bounded Myers** (`maxD` and cell budget); huge anchor-free regions degrade to an
  O(N) block replacement with positional `Modified` pairing. Memory is bounded — no O(D²) trace.
- **Real character-level intra-line diffs** (bounded Myers on the middle segment) produce multiple
  `CharRange`s per line, not just prefix/suffix.
- **Moved-block detection**: unmatched Removed/Added lines with identical normalized content are
  paired into `ChangeType::Moved` with `movedToLine`; can be disabled via `DiffOptions`.
- Options: ignore whitespace, ignore case, ignore EOL, detect moves; trailing-line semantics match
  Scintilla (`lines = '\n' count + 1`).

**View (`widgets/CompareWidget`)**
- Independent **read-only editor copies** — TabManager pages are never reparented; closing the
  comparison leaves all tabs intact.
- **Async computation** via `QtConcurrent::run` + `QFutureWatcher` with generation tokens;
  inputs above 256 KB leave the UI thread and show a "Comparing…" status. Small inputs stay
  synchronous for zero latency.
- Scintilla `SCI_ANNOTATIONSETTEXT` visual placeholders align the two panes without touching the
  text buffer; markers (Added/Removed/Modified/Moved) and an indicator highlight intra-line ranges.
- **Vertical scroll sync maps document lines through the alignment table**, not raw scrollbar
  values, so annotation placeholders no longer cause drift.
- **Diff mini-map** (`widgets/DiffMiniMap`): self-painted distribution strip, click to navigate.
- `F8` / `Shift+F8` navigation, 16 MB per-side guard.
- Git/SVN comparison uses `QProcess` with argument lists (no shell, no linked third-party
  libraries), preserving the zero-dependency rule.

## 11. Tests (TDD)

All features are covered by `tests/test_*.cpp` run through `ctest`:

```bash
cd npp-linux
ctest --test-dir build --output-on-failure
```

Notable suites: `TestDiffEngine` (correctness, worst-case bounded time, anchors, multi-segment
intra-line, Moved, async, scroll mapping, mini-map, selection compare, config migration),
`TestHexView` (raw-byte fidelity, high offsets, address width, theme, binary auto-open,
monospace grid), `TestLocalization` (zero Chinese in English mode), `TestUrlLink`, `TestFold`,
`TestShortcuts`, `TestPerformance`.
